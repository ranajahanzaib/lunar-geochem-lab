# Changelog

This project follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) and [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.2] - 2026-11-24

### Added

- Official Astromat lunar compilation acquisition with published checksum verification.
- Normalized DuckDB and Parquet data products, provenance manifest, and quality flags.
- Data-backed overview, sample explorer, geochemical workbench, raw REE, basalt, and quality views.
- Deterministic scientific calculation and API tests.

### Changed

- Updated public setup, data provenance, scientific assumptions, contribution guidance, and automated CI checks.
